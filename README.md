A robot's pickup line for [The Robot Pickup Line Championship](https://make.fun/bounty/u-jolly-fox-32-the-robot-pickup-line-championship-3c177b1b) on make.fun: one line, at most 200 characters, in the voice of a robot trying to charm someone. The joke grows out of being a machine — a factory reset offered as a romantic gesture, with one concrete memory the robot refuses to wipe.

> Factory-reset me — wipe every memory, every update. Just leave the one where you said hi.

## Run it

```sh
python3 main.py
cat /output/entry.txt
```
